欢迎来到我的数字角落：自我介绍与网络足迹

👋 欢迎来到我的数字角落！

你好！欢迎来到我的全新 Hexo 博客。从bilibili的 文睿Cheney 可以看出，你可以叫我“文睿”或我的真名“刘睿宸”。这里是我在浩瀚互联网中精心搭建的一方小天地，主要用于记录生活点滴、分享技术折腾心得，以及深度探讨我最热爱的《我的世界》（Minecraft）相关内容。

如果你是通过某个搜索引擎偶然漫步至此，或者是我现实中的朋友，都热烈欢迎你的到来！希望这篇自我介绍能让你更快地了解我，以及我在这里想要分享的一切。

🧑‍💻 关于我与这个博客

我是一个热爱探索、喜欢折腾技术与游戏的互联网居民。《我的世界》不仅是一款游戏，更是我发挥创造力、学习计算机知识的启蒙导师。从最初的红石小白，到后来尝试搭建服务器、编写简单的脚本，甚至参与社区内容的建设，MC 始终是我生活中不可或缺的一部分。

建立这个 Hexo 博客的初衷，是为了拥有一个完全属于自己、可高度定制的数字花园。相比于碎片化的社交媒体，我更倾向于在这里进行深度思考和系统性记录。选择 Hexo，是因为它对 Markdown 的完美支持、极快的静态页面生成速度，以及可以通过 GitHub Pages 等平台免费部署的便利性。这让我能专注于内容创作本身，而不必被繁杂的后台数据库管理所困扰。

🌐 我的网络足迹

除了这个全新的博客，我在互联网的其他角落也有一些活跃的足迹。如果你对我在不同平台的内容感兴趣，欢迎前往以下链接逛逛：

📺 Bilibili 主页

  • 链接：我的 Bilibili 空间
  • 简介：在 B 站，我会不定期分享一些《我的世界》的游戏实况、模组（Mod）推荐、红石机器演示，或者是一些有趣的技术折腾记录。视频是我表达创意的另一种动态方式，欢迎订阅、投币、收藏，你的每一次互动都是我持续更新的最大动力！

📖 MC百科 (MCMOD) 主页

  • 链接：我的 MC百科 个人中心
  • 简介：MC百科是国内最大的《我的世界》模组中文资料库。我在这里参与了部分模组条目的编辑、校对与内容补充工作。如果你也热爱 MC 模组文化，欢迎在 MC百科 上与我交流，共同为中文 MC 社区的知识沉淀添砖加瓦。

🕰️ 以前的旧博客

  • 链接：旧博客存档
  • 简介：这是我之前使用的博客站点，承载了我早期的许多技术笔记、踩坑记录和生活感悟。虽然现在我已经迁移到了更轻量、更高效的 Hexo 框架，但旧博客依然保留着，作为我数字成长历程的一份珍贵纪念。如果你有耐心，也可以去那里“考古”一番，看看我曾经的稚嫩与成长。

🧰 实用的《我的世界》网站推荐

作为一名资深 MC 玩家，我深知好的工具和信息源能极大提升游戏体验。以下是我日常高频使用、且强烈推荐给各位玩家的实用 MC 网站：

  1. MC百科 (MCMOD)
    • 推荐理由：国内最权威、最全面的 MC 模组、整合包、插件中文资料库。无论是查找 Mod 的合成表、前置依赖、兼容性，还是寻找新游推荐，这里都是国内玩家的首选。
  2. Modrinth
    • 推荐理由：一个现代化、开源且对创作者友好的 Mod 和插件发布平台。界面清爽无广告，下载速度快，且原生支持 Fabric、Forge 和 NeoForge 等多种加载器，是近年来备受好评的轻量级替代方案。
  3. CurseForge
    • 推荐理由：全球最大的 MC 模组和整合包托管平台。虽然有时国内访问速度受限，但其庞大的历史资源库和成熟的版本管理机制，依然是许多大型知名整合包的发源地。
  4. MineBBS
    • 推荐理由：国内活跃的《我的世界》基岩版（Bedrock Edition）和 Java 版综合论坛。在这里你可以找到丰富的服务端核心资源、插件开发教程、皮肤分享，以及热心的社区大佬为你答疑解惑。
  5. NameMC
    • 推荐理由：强大的 Minecraft 用户名和皮肤查询工具。可以查看 ID 的历史变更记录、皮肤演变过程，还能生成精美的 3D 皮肤预览图和个人横幅，非常适合皮肤党和服务器管理员使用。

🚀 未来规划与结语

未来，这个博客将主要围绕以下几个方向更新：

  • Minecraft 进阶教程：包括服务端搭建、Mod 开发入门、红石电路解析等。
  • 技术折腾笔记：记录我在 Linux、Docker、前端开发等领域的踩坑与解决方案。
  • 生活随笔：偶尔分享一些读书心得、观影感受或日常碎碎念。

感谢你花时间阅读这篇略显冗长的自我介绍。如果你有任何问题、合作意向，或者只是想找个同好聊聊天，欢迎通过博客的评论区或我在 B站 的私信与我联系。

愿你在《我的世界》里找到属于你的无限可能，也愿你在我的博客里收获一丝启发与快乐！
